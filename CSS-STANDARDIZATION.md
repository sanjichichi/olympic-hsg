# OLIMPIC HSG – CSS Standardization v2

This version adds a consolidated `css/responsive.css` layer to all HTML pages.

Goals:
- Prevent horizontal overflow.
- Improve mobile/tablet behavior.
- Make images/media responsive.
- Improve form controls and touch targets.
- Collapse common grids to one column on small screens.
- Preserve existing page-specific CSS and JavaScript.

This is a safe first-pass responsive layer; existing CSS files are retained so functionality and visual design are not intentionally removed.
